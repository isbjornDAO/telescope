# Open questions

Unresolved as of v0.1. Each of these blocks a piece of the build. Items resolved with starting values in [Build decisions](build-decisions.md) are marked **(starting value set)**.

## World

- Exact scout protocol: what a scout may ask, what it may reveal, what it pays for. **(starting value set)**
- Default scout budget and how additional capacity is priced. **(starting value set)**
- Faction founding requirements: minimum crews, minimum regions, minimum standing.
- Whether alliances can span more than two factions.

## Trust

- Trust score formula: decay per hop, relative weight of in-person, shipped-together and shared-vision links. **(starting value set)**
- Elder admission process and term.
- Slashing panel composition and appeal process. **(starting value set)**
- How a region's in-person verification is attested on-chain without a doxxing risk.

## Seasons

- Threshold values per round, per tournament. **(starting value set)**
- Research review pool size and reviewer assignment. **(starting value set)**
- The 90-day retention metric: exactly what counts as an active user of a GTM product. **(starting value set)**
- Anti-collusion weights. **(starting value set)**

## Platform

- Everything in the Iggy L1 brief: gas token, VM, ZK stack, validator set, on-chain vs off-chain boundary.
- Builder's Hub integration surface and what can be exported as a proof today.
- Conservation share of revenue and the named recipient.

## Brand

- Trademark check on "Telescope".
- Visual identity: the bear, the ice, the map.
